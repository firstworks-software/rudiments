Detailed Description

The cgihttpserverapi class implements the httpserverapi, input, and output interfaces such that web based applications can be developed as CGIs.

Note that this class is not intended to be instantiated directly.

Rather, an application should define HTTP_MODULE_CGI, include <rudiments/httpserverapimain.h>, and then implement the method httpModuleMain(httpserverapi *sapi) as the main body of the application. The methods of "sapi" can then be used directly.
